# Claude Usage Monitor

A small menu-bar (macOS) / system-tray (Windows, later) app that shows your Claude plan usage:
percentage consumed in the 5-hour session and weekly windows, and when each resets. Click it for
a floating window with the same numbers, a nicer presentation, and links to the Claude usage and
settings pages.

Built with Tauri 2, Rust, React and TypeScript. No third-party UI libraries.

Status: project bootstrapped, no code yet. See `CLAUDE.md` for conventions and
`docs/research-usage-monitors.md` for the data-source research.

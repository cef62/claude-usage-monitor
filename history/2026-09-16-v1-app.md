## Summary

Implemented v1 of the Claude Usage Monitor: a Tauri 2 + Rust + React 19 macOS menu bar app
that polls the Anthropic OAuth usage endpoint, reads the Claude Code credential from the
macOS Keychain (with a config-dir fallback), and shows session/weekly usage percentages and
reset countdowns in the tray title. A click opens a popover with usage bars, an elapsed-time
marker, and links to the claude.ai usage/billing pages. Rust owns credentials, HTTP, polling,
and OS integration; React only renders what the Rust side emits.

## Initial Request

Build the v1 app per the approved design spec
(`docs/superpowers/specs/2026-09-16-usage-monitor-v1-design.md`) and implementation plan
(`docs/superpowers/plans/2026-09-16-usage-monitor-v1.md`): scaffold the Tauri/React project,
implement credential parsing and usage normalization, the poll loop with backoff/cooldown,
the tray title and popover UI, then bring the branch to a shippable state (full verify, a
release build, docs, and a history record).

## Acceptance Criteria

- [x] Credentials are read from macOS Keychain (`Claude Code-credentials`) with a
      `$CLAUDE_CONFIG_DIR/.credentials.json` fallback; a missing/partial blob yields "no
      token", never a crash.
- [x] Usage is fetched from `GET https://api.anthropic.com/api/oauth/usage` with the required
      headers (`Authorization`, `anthropic-beta: oauth-2025-04-20`, `User-Agent:
      claude-code/<version>`), normalized from `limits[]` with fallback to flat
      `five_hour`/`seven_day*` fields, dropping null-utilization/no-`resets_at` entries.
- [x] Poll loop respects the rate-limit discipline: base 180s interval, never two successful
      fetches closer than 120s, one in-flight request at a time, 429 honors `Retry-After` else
      exponential backoff capped at 15 min, 401 latches until the credential store changes.
- [x] Tray title renders session/weekly countdowns (`⏱ 48% ↻2h13m · 📅 64% ↻3d4h`), shows
      `⏱ ! login` when unauthenticated, and appends ` (429)` when rate limited.
- [x] Popover shows usage bars, an elapsed-time marker, and opener links to claude.ai usage
      and billing pages via `plugin:opener|open_url` (never by navigating the webview).
- [x] Capabilities file grants exactly what the code uses (`opener:allow-open-url` scoped to
      `https://claude.ai/*`; no entries for plain app commands).
- [x] `pnpm verify` passes: Biome clean, `tsc --noEmit` clean, 7 Vitest tests, `cargo fmt
      --check` silent, `cargo clippy -D warnings` clean, 22 Rust tests.
- [x] `pnpm tauri build` produces a `.app` and `.dmg` under
      `src-tauri/target/release/bundle/`.
- [x] README and `CLAUDE.md` describe v1 behavior, development commands, and known limits.

## Final Notes

- The API surface is percentages-only; there are no token counts anywhere, per the data-source
  spec in `CLAUDE.md`.
- Rate-limit discipline (180s base poll, 120s minimum gap between successful fetches, one
  in-flight request, 429/401 handling) is implemented in `src-tauri/src/poll.rs` and covered
  by inline `#[cfg(test)]` tests.
- No third-party UI libraries, no ESLint/Prettier (Biome only), no Windows tray support yet —
  all per `CLAUDE.md`'s "What NOT to Do" section.
- Outstanding for later versions (see README "Not yet"): threshold notifications, a settings
  UI, Windows tray icon, launch-at-login, code signing.

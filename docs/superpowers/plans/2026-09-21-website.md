# Static website on GitHub Pages — implementation plan

## Context

The project has no web presence beyond the GitHub README. A small static site presents the
tool, offers the downloads, carries the user guide and the changelog, and updates itself on
every release without manual work. Decisions taken in brainstorming:

- **Tool:** bare Astro (one dev dependency, no theme). Markdown import is built in.
- **Content:** hand-written landing page; the guide page renders `README.md`, the changelog
  page renders `CHANGELOG.md` — both stay single sources of truth, the site never copies them.
- **Downloads:** direct asset links built from `package.json` version.
- **Deploy:** new `pages.yml` on push to `main`, path-filtered. The Version Packages PR merge
  touches `CHANGELOG.md` + `package.json`, so every release redeploys the site with the new
  version and notes. Site URL: `https://cef62.github.io/claude-usage-monitor/`.

Branch: `feat/website` off `main` (v0.10.0).

## Global Constraints

- Repo conventions (CLAUDE.md): pnpm only; Biome (2-space, single quotes, trailing commas,
  semicolons, lineWidth 100); plain CSS, system font stack, `prefers-color-scheme` light/dark;
  no UI libraries, no CSS frameworks, no icon packs. Comments explain why, not what.
- GitHub repo: `cef62/claude-usage-monitor`. Site base path: `/claude-usage-monitor`.
- Release asset names (from README): `Claude.Usage.Monitor_<ver>_aarch64.dmg` and
  `Claude.Usage.Monitor_<ver>_x64-setup.exe` under
  `https://github.com/cef62/claude-usage-monitor/releases/download/v<ver>/`.
- `CHANGELOG.md` bullets have the shape `- 2a395a2: text` (7-hex-char commit prefix); the same
  pattern is stripped by the awk in `.github/workflows/build-release.yml`.
- `README.md` uses repo-relative links (`docs/screenshots/*.png`, `CONTRIBUTING.md`, `LICENSE`)
  and `#anchors`.
- Workflow actions are SHA-pinned with a `# vX.Y.Z` comment (see `.github/workflows/ci.yml`).
- Out of scope: custom domain, search, sidebar, versioned docs, analytics, RSS.
- Astro version: latest stable at install time (`pnpm add -D astro`); do not guess a number.

## Task 1: Astro site under `site/`

Files: `package.json` (devDependency `astro`, scripts), `pnpm-lock.yaml`, `.gitignore`,
`biome.json`, and everything under `site/`.

Layout:

```
site/
  astro.config.mjs        site/base, markdown plugins
  tsconfig.json           extends astro/tsconfigs/strict
  src/
    layouts/Base.astro    <head>, header nav (Home · Guide · Changelog · GitHub), footer, imports styles.css
    styles.css            plain CSS, system font stack, prefers-color-scheme, phone-width OK (16px gutter, no horizontal scroll)
    pages/
      index.astro         landing
      guide.astro         import Readme from '../../../README.md'; <Readme.Content />
      changelog.astro     import Log from '../../../CHANGELOG.md'; <Log.Content />
  plugins/
    rehype-repo-links.mjs   relative href/src in README → GitHub blob / raw URLs
    remark-commit-links.mjs "- abc1234: text" bullets in CHANGELOG → commit link
```

Root `package.json` gets `"astro"` in `devDependencies` (latest) and scripts:

```json
"site:dev": "astro dev --root site",
"site:build": "astro build --root site",
"site:preview": "astro preview --root site"
```

`site/astro.config.mjs`: `site: 'https://cef62.github.io'`, `base: '/claude-usage-monitor'`,
`markdown: { remarkPlugins: [remarkCommitLinks], rehypePlugins: [rehypeRepoLinks] }`. Internal
links in `.astro` files use `import.meta.env.BASE_URL` (never hard-code the base).

`biome.json` `files.includes`: add `"!**/site/dist", "!**/site/.astro"`.
`.gitignore`: add `site/dist` and `site/.astro`.

**index.astro** — hero: app name, one-paragraph pitch drawn from the README intro (tiny
menu bar / tray app, session + weekly percentages and reset countdowns, reuses the Claude Code
login, MIT, not affiliated with Anthropic). Screenshots imported from `docs/screenshots/*.png`
via Vite asset imports (`import macTray from '../../../docs/screenshots/mac-tray.png'`, use
Astro's `<Image>` or plain `<img src={macTray.src}>`; no copies of the PNGs). Downloads:
`import pkg from '../../../package.json'`; two buttons labelled with the version
("macOS (Apple Silicon) · v0.10.0", "Windows x64 · v0.10.0") linking to the two release assets
under Global Constraints, plus an "all releases" link to
`https://github.com/cef62/claude-usage-monitor/releases`. Under the buttons, the unsigned-build
notice (one line macOS: Privacy & Security → Open Anyway or `xattr -cr`; one line Windows:
SmartScreen → More info → Run anyway) and "Requires Claude Code installed and logged in
(`claude auth login`)". A short "How it works" paragraph (reads the Claude Code OAuth token,
calls `api.anthropic.com/api/oauth/usage`, percentages only, token never stored/logged/sent
elsewhere) and links to the Guide and Changelog pages.

**guide.astro** — full README rendered inside the layout. `rehype-repo-links.mjs`: walk the
hast tree (hand-written recursive walk over `node.children`, no `unist-util-visit`); for
`img` `src` and `a` `href` values that do not start with `http://`, `https://`, `/`, `#`, or
`mailto:` — images become
`https://raw.githubusercontent.com/cef62/claude-usage-monitor/main/<path>`, links become
`https://github.com/cef62/claude-usage-monitor/blob/main/<path>`.

**changelog.astro** — full CHANGELOG rendered inside the layout. `remark-commit-links.mjs`:
walk the mdast tree; in each `listItem` whose first paragraph's first `text` node starts with
`/^([0-9a-f]{7}): /`, replace that prefix with a `link` node
(`url: https://github.com/cef62/claude-usage-monitor/commit/<hash>`, text `<hash>`) followed
by a text node `" "` + the remainder. No hash prefix visible as plain `abc1234:` text.

Both plugins are small plain `.mjs` (~15 lines each), used only via `astro.config.mjs`. Tests:
each plugin gets one Vitest spec in `test/` (`test/site-plugins.test.ts`) that builds a tiny
tree by hand, runs the plugin, and asserts the rewritten URL / link node — vite.config.ts
already includes `test/**/*.test.ts`. Write the tests first (TDD).

Verify: `pnpm install`; `pnpm site:build` produces `site/dist/index.html`,
`site/dist/guide/index.html`, `site/dist/changelog/index.html` with `/claude-usage-monitor/`
prefixed asset URLs; `grep -c 'raw.githubusercontent' site/dist/guide/index.html` > 0;
`grep -c '/commit/' site/dist/changelog/index.html` > 0; no literal `abc1234: ` pattern in
changelog HTML (`grep -E '>[0-9a-f]{7}: ' site/dist/changelog/index.html` empty);
`pnpm verify` green. Commit.

## Task 2: Workflows

Files: `.github/workflows/pages.yml` (new), `.github/workflows/ci.yml`.

`pages.yml`:

```yaml
name: Pages

on:
  push:
    branches: [main]
    paths:
      - site/**
      - README.md
      - CHANGELOG.md
      - package.json
      - docs/screenshots/**
      - .github/workflows/pages.yml
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - checkout, pnpm/action-setup, setup-node 24 with cache pnpm  (copy the exact pinned `uses:` lines from ci.yml)
      - run: pnpm install --frozen-lockfile
      - run: pnpm site:build
      - uses: actions/configure-pages@<sha> # vX
      - uses: actions/upload-pages-artifact@<sha> # vX
        with:
          path: site/dist
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@<sha> # vX
```

Resolve `<sha>` for the three Pages actions with
`gh api repos/actions/<name>/git/ref/tags/<latest-tag> --jq .object.sha` (dereference
annotated tags if needed: `gh api repos/actions/<name>/git/tags/<sha> --jq .object.sha`) and
note the tag in the comment, matching the style in `ci.yml`.

`ci.yml`: in job `verify-and-build`, add `- run: pnpm site:build` right after
`- run: pnpm verify`.

Verify: `pnpm site:build` still passes locally; YAML parses (`node -e` with a YAML parser is
not available — eyeball indentation, or `gh workflow view` after push is fine). Commit.
